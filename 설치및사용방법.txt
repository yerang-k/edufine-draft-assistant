📝 K-에듀파인 품의 도우미 (AI 품목/기안문 자동입력) v2.5.2
   - 설치 및 상세 사용 매뉴얼 -
========================================================================

"쇼핑몰 장바구니 캡처 한 장이면 기안문 작성부터 표 셀 입력까지 1초 만에 끝!"

지원 브라우저: 크롬(Chrome), 네이버 웨일(Whale), 마이크로소프트 엣지(Edge)


------------------------------------------------------------------------
💻 1단계: 브라우저에 프로그램 설치하기 (최초 1회, 1분 소요)
------------------------------------------------------------------------
1. 브라우저를 열고 주소창에 아래 주소를 입력하고 엔터(Enter)를 칩니다:
   - 크롬(Chrome) : chrome://extensions
   - 네이버 웨일  : whale://extensions
   - 엣지(Edge)   : edge://extensions

2. 화면 우측 상단의 [개발자 모드] 스위치를 켭니다 (파란색 활성화).

3. 화면 좌측 상단에 나타나는 [압축해제된 확장 프로그램을 로드합니다]
   (웨일은 [압축 해제된 확장앱 설치]) 버튼을 클릭합니다.

4. 압축을 푼 'edufine-draft-assistant' 폴더를 선택하고 [폴더 선택]을 누릅니다.

5. 브라우저 우측 상단 퍼즐 조각(🧩) 아이콘을 눌러 '에듀파인 품의 도우미'
   옆의 📌(고정핀)을 클릭하여 상단에 고정합니다.


------------------------------------------------------------------------
🔑 2단계: 무료 AI (Gemini) API Key 발급 및 등록 (최초 1회)
------------------------------------------------------------------------
구글에서 무료로 제공하는 AI 분석 키입니다. 비용이 일체 발생하지 않습니다.

1. 구글 AI 스튜디오 사이트에 접속하여 구글 계정으로 로그인합니다:
   👉 https://aistudio.google.com/app/apikey

2. 파란색 [Create API key] (또는 'Get API key') 버튼을 누릅니다.

3. 생성된 긴 영문/숫자 키 옆의 [Copy] 아이콘을 눌러 복사합니다.

4. 브라우저 우측 상단에서 '에듀파인 품의 도우미(📝)' 아이콘을 눌러 엽니다.

5. 우측 상단 [⚙️ 설정] 버튼을 누릅니다.

6. [Gemini API Key] 칸에 복사한 키를 붙여넣고 [연결 테스트 및 저장]을 누릅니다.
   - "✅ 연결 성공! API Key가 안전하게 저장되었습니다." 문구가 뜨면 완료!


------------------------------------------------------------------------
🚀 3단계: 실전 품의 작성 방법
------------------------------------------------------------------------

[🅰️ 단일 예산 품의 (예산 1개로 구매할 때)]
1. 에듀파인에 접속하여 [품의등록] 화면을 엽니다.
2. [예산선택] 버튼을 눌러 사용할 예산을 먼저 지정해 둡니다. (★필수!)
3. 쇼핑몰 장바구니에서 키보드의 'Win + Shift + S'를 눌러 상품명과 가격을 캡처합니다.
4. 품의 도우미 사이드 패널에 'Ctrl + V'로 붙여넣습니다. (여러 장 가능)
5. 물품 용도(교육활동용, 학급운영용 등) 선택 후 [✨ AI 상품 분석 및 기안문 작성] 클릭!
6. 수량 조절이 필요하면 [-], [+] 버튼으로 변경합니다. (금액/기안문 자동 재계산)
7. 초록색 [⚡ 에듀파인 화면에 즉시 입력 (기안문 + 품목)] 버튼을 누르면
   제목, 본문 개요, 품목 표 행추가 및 셀 타이핑이 1초 만에 완성됩니다!

[🅱️ 다중 예산 분할 품의 (예산 2개 이상을 나누어 구매할 때)]
1. 품의 도우미 상단의 [다중 예산 분할 품의] 탭을 클릭합니다.
2. 에듀파인 화면 [예산내역] 표에서 1번 예산 행을 클릭합니다.
3. 1번 예산 캡처를 넣고 [1번 예산 품목 AI 분석] ➜ [에듀파인 표에 1번 예산 품목 즉시 입력] 클릭!
4. [➕ 다음 예산(2번 예산) 품목 입력으로 넘어가기] 클릭!
5. 에듀파인 화면 [예산내역] 표에서 2번 예산 행을 클릭합니다.
6. 2번 예산 캡처를 넣고 AI 분석 ➜ [에듀파인 표에 2번 예산 품목 즉시 입력] 클릭!
   (기존 1번 품목 뒤에 지워지지 않고 순서대로 이어붙여집니다.)
7. 모든 품목 입력 후 하단 [전체 품목 종합 기안문 자동 생성] 클릭!
8. 초록색 [에듀파인 화면에 [최종 기안문(제목+본문)] 즉시 입력]을 누르면 완성!


------------------------------------------------------------------------
💡 선생님들을 위한 안내 팁
------------------------------------------------------------------------
* 에듀파인 시스템 규칙상 예산이 먼저 지정되어 있어야 품목 행을 추가할 수
  있으므로, 품목 입력 전 에듀파인에서 예산을 먼저 선택해 주세요.
* 단위는 학교별·품목별 기준이 다양하여 결재 반려를 방지하고자 에듀파인
  기본값인 '선택'으로 안전하게 유지됩니다.
* 구글 무료 API는 분당 요청 횟수 제한이 있어 연속으로 빠르게 누르면 일시
  대기 안내가 뜰 수 있습니다. 약 20~30초 후 다시 누르시면 정상 작동합니다.
