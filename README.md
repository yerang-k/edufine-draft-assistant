# 📝 K-에듀파인 품의 도우미 (Edufine Draft Assistant) v2.5.3

> **"쇼핑몰 장바구니 캡처 한 장이면 끝!"**  
> 쇼핑몰(쿠팡, 네이버, S2B 등)의 장바구니나 견적서를 캡처해서 붙여넣으면, AI가 품목명·규격·수량·가격을 자동 분석하여 **표준 기안문(제목/본문) 작성**과 **에듀파인 표 자동 셀 입력(행추가 및 타이핑)**까지 원클릭으로 완료해 주는 교원 전용 업무 자동화 도구입니다.

---

## 🌟 핵심 주요 기능

1. **초간편 이미지 캡처 붙여넣기 (`Win + Shift + S` ➜ `Ctrl + V`)**
   - 별도 파일 저장 필요 없이 캡처 후 사이드 패널에 붙여넣기만 하면 즉시 등록됩니다.
2. **단일 예산 품의 (원클릭 자동 완성)**
   - 예산이 1개일 때: 캡처 등록 ➜ AI 분석 ➜ `[⚡ 에듀파인 화면에 즉시 입력]` 한 번으로 기안문(제목+본문)과 품목 표 전체가 1초 만에 자동 완성됩니다.
3. **다중 예산 분할 품의 (여러 예산 순차 입력 지원)**
   - 예산이 2개 이상일 때: 1번 예산 품목 입력 ➜ 2번 예산 품목 입력 ➜ 전체 품목 합산 종합 기안문 작성 및 본문 입력까지 순서대로 진행 가능합니다.
4. **구매 수량 빠른 조절 (`-` / `+` 스텝 버튼)**
   - AI 분석 후 장바구니 수량이 달라져도 화면에서 `[-]`, `[+]` 버튼으로 수량을 바꾸면 총 소요예산과 기안문 금액이 실시간 자동 재계산됩니다.
5. **K-에듀파인 화면 즉시 자동 입력 (Nexacro 엔진 정밀 연동)**
   - 품의 제목, 본문 개요 입력은 물론 에듀파인 품목 표의 `[행추가 +]` 클릭 및 내용·규격·수량·예상단가 셀 타이핑을 사람 대신 100% 자동으로 수행합니다.
   - 단위는 에듀파인 규정상 기본값인 '선택'으로 안전하게 유지됩니다.

## 💻 1단계: 브라우저에 프로그램 설치하기 (최초 1회, 1분 소요)

*지원 브라우저: 크롬(Chrome), 네이버 웨일(Whale), 마이크로소프트 엣지(Edge)*

1. 브라우저를 엽니다.
2. 주소창에 아래 주소를 입력하고 엔터(Enter)를 칩니다:
   - **크롬(Chrome)**: `chrome://extensions`
   - **네이버 웨일(Whale)**: `whale://extensions`
   - **엣지(Edge)**: `edge://extensions`
3. 화면 우측 상단의 **[개발자 모드]** 스위치를 켭니다 (파란색 활성화).
4. 좌측 상단에 나타나는 **[압축해제된 확장 프로그램을 로드합니다]** (웨일은 [압축 해제된 확장앱 설치]) 버튼을 클릭합니다.
5. 전달받은 **`edufine-draft-assistant` 폴더**를 선택하고 [폴더 선택]을 누릅니다.
6. 브라우저 우측 상단 퍼즐 조각(🧩) 모양 아이콘을 눌러 **'에듀파인 품의 도우미'** 옆의 📌(고정핀)을 눌러 상단에 고정합니다.

---

## 🔑 2단계: 무료 AI(Gemini) API Key 등록하기 (최초 1회, 무료)

Google에서 교사 및 일반 사용자에게 무료로 제공하는 Gemini API 키를 발급받아 등록합니다.

1. 인터넷 창에서 **[Google AI Studio (https://aistudio.google.com/app/apikey)](https://aistudio.google.com/app/apikey)** 에 접속하여 구글 계정으로 로그인합니다.
2. 파란색 **[Create API key]** (또는 'Get API key') 버튼을 클릭합니다.
3. 생성된 긴 영문/숫자 키 옆의 **[Copy]** 를 눌러 복사합니다.
4. 브라우저 상단에서 **에듀파인 품의 도우미 아이콘(📝)**을 클릭하여 우측 사이드 패널을 엽니다.
5. 우측 상단의 **`⚙️ 설정`** 버튼을 누릅니다.
6. **Gemini API Key** 입력란에 복사한 키를 붙여넣고 **[연결 테스트 및 저장]**을 누릅니다.
   - *"✅ 연결 성공! API Key가 안전하게 저장되었습니다."* 문구가 뜨면 완료!

## 📖 3단계: 품의 작성 및 실전 사용 방법

### 🅰️ [단일 예산 품의] (가장 일반적인 품의: 예산 1개 사용)

1. **에듀파인 접속**:
   - 에듀파인에 로그인하여 **[품의등록]** 화면을 엽니다.
   - **[예산선택]** 버튼을 눌러 사용할 **예산(1개)을 먼저 지정**해 둡니다. *(중요!)*
2. **상품 캡처 및 붙여넣기**:
   - 쇼핑몰(쿠팡, 네이버, S2B 등) 장바구니 화면에서 키보드의 **`Win + Shift + S`** 를 눌러 품목명과 가격이 보이게 드래그 캡처합니다.
   - 품의 도우미 사이드 패널의 붙여넣기 영역을 클릭하고 **`Ctrl + V`** 를 누릅니다. (여러 장 캡처해서 계속 붙여넣어도 됩니다!)
3. **용도 선택 및 AI 분석**:
   - **물품 용도**(교육활동용, 학급운영용, 실습재료용 등)를 선택합니다.
   - 파란색 **[✨ AI 상품 분석 및 기안문 작성]** 버튼을 클릭합니다.
4. **수량 확인 및 빠른 조절**:
   - AI가 품목명, 규격, 수량, 단가를 분석해 카드 형태로 보여줍니다.
   - 수량이 변경되었으면 `[-]`, `[+]` 버튼으로 조절합니다. (총금액과 기안문이 실시간 자동 갱신됩니다.)
5. **에듀파인 화면에 즉시 입력**:
   - 초록색 **[⚡ 에듀파인 화면에 즉시 입력 (기안문 + 품목)]** 버튼을 클릭합니다!
   - 1~2초 만에 에듀파인 화면의 **제목**, **본문 개요**, 그리고 **품목 표의 [행추가] 및 셀 타이핑**이 자동으로 완료됩니다!

---

### 🅱️ [다중 예산 품의] (예산 2개 이상을 나누어 품의할 때)

1. 품의 도우미 상단에서 **[다중 예산 분할 품의]** 탭을 클릭합니다.
2. **1번 예산 품목 입력**:
   - 에듀파인 화면의 [예산내역] 표에서 **1번 예산 행을 클릭**합니다.
   - 품의 도우미에 1번 예산으로 살 물품 캡처를 붙여넣고 **[1번 예산 품목 AI 분석]**을 누릅니다.
   - 파란색 **[에듀파인 표에 1번 예산 품목 즉시 입력]** 버튼을 누르면 1번 예산 품목이 표에 쏙 들어갑니다.
3. **2번 예산 품목 입력**:
   - 품의 도우미에서 **[➕ 다음 예산(2번 예산) 품목 입력으로 넘어가기]** 버튼을 클릭합니다.
   - 에듀파인 화면의 [예산내역] 표에서 **2번 예산 행을 클릭**합니다.
   - 2번 예산으로 살 물품 캡처를 붙여넣고 AI 분석 후 **[에듀파인 표에 2번 예산 품목 즉시 입력]**을 누릅니다. (기존 1번 품목 뒤에 덮어쓰지 않고 순서대로 이어붙여집니다!)
4. **전체 종합 기안문 작성 및 최종 본문 입력**:
   - 모든 예산의 품목 입력이 끝나면 아래쪽의 **[전체 품목 종합 기안문 자동 생성]**을 누릅니다. (모든 품목의 총합계 금액이 한 번에 계산됩니다.)
   - 초록색 **[에듀파인 화면에 [최종 기안문(제목+본문)] 즉시 입력]**을 누르면 기안문까지 깔끔하게 완성됩니다!

## 💡 선생님들을 위한 꿀팁 & 주의사항

* 💡 **에듀파인 예산 먼저 선택하기**: 에듀파인 시스템 규정상 예산이 먼저 지정되어 있어야 품목 행을 추가할 수 있습니다. 품목 입력 전 에듀파인 화면에서 예산을 먼저 조회/선택해 주세요.
* 💡 **단위 기본값 안내**: 학교 에듀파인은 통상 '선택' 상태로 두거나 품목에 맞게 결재선에서 확인하므로, 오류 방지를 위해 단위는 자동으로 '선택'으로 유지됩니다.
* 💡 **AI 분석 오류(분당 한도 초과) 발생 시**: 무료 API 특성상 1분에 여러 번 연속 분석을 누르면 잠시 대기 안내가 뜰 수 있습니다. 약 20~30초 후 다시 누르시면 정상 작동합니다.
